Step 1:To create a Notebook, click on "New Notebook".

Step 2:After you navigate to the Kaggle Code page.

Step 3:After this process, cloud resources will be allocated for you and a notebook will be created instantly.

Step 4:In your "New Notebook" click the file in select "Import Notebook"
  
Step 5:After that the "Import Notebook" will be open. click on the "Browse File"

step 6:In the files tab select that open  iemocap-1.ipynb, file to execute the model and fetch the results of your code it will open on your Kaggle Notebook.

Step 7:To import a dataset, click on the "Add data" button under the "Save Version" button on the right menu and select the dataset.
 Dataset Link:
IEMOCAP - https://www.kaggle.com/datasets/rumaiya/iemocap

Step 8:Execute each cell by pressing Ctrl+Enter on the keyboard to obtain results
